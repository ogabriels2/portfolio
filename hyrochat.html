HyroChat

Triagem guiada para a fintech Sanhyro. O chatbot organiza pedidos frequentes e prepara o caminho para o atendimento humano quando uma conversa precisa continuar no WhatsApp.

Projeto em equipePython · NiceGUI · PostgreSQLÁrvore de decisão em JSON
Experimentar o fluxo Ver apresentação

01 / O problema

As dúvidas chegavam pelo mesmo canal usado para resolver casos complexos.

A Sanhyro concentrava o atendimento no WhatsApp. O projeto partiu da necessidade de separar as perguntas recorrentes e levar cada pessoa ao próximo passo com mais contexto.

Linha de base

até 2 dias

de espera relatados pela empresa

O cenário descrito no diagnóstico do projeto, em períodos de maior demanda.

Equipe de atendimento

até 5

pessoas na equipe

Uma equipe enxuta precisava alternar dúvidas simples e solicitações que pediam análise humana.

Triagem guiada

3 passos

01Assunto02Detalhe03Destino

para chegar ao próximo passo

Escolher um assunto, detalhar o pedido e decidir se ele segue para autoatendimento ou para um atendente.

Os dois primeiros dados são contexto relatado pela Sanhyro no diagnóstico. São uma linha de base do problema, não uma medição de redução após o projeto.

02 / Experimente

Um caminho curto, com o próximo passo sempre visível.

Escolha “Empréstimo / Crédito” e depois “Simular um empréstimo” para acompanhar a triagem descrita no código do projeto.

Ela roda nesta página sem conexão ao servidor, banco de dados ou WhatsApp do projeto. A transferência real é mostrada como uma mensagem preparada.

03 / O fluxo técnico

Regras explícitas ligam a escolha à ação.

O conteúdo mora em uma árvore JSON. O motor valida a escolha, mantém o caminho da conversa e encaminha o caso quando as respostas prontas chegam ao limite.

ETAPA SELECIONADA

O assunto inicia o fluxo

A pessoa pode escolher uma opção clicável ou informar o número correspondente. A validação impede avançar para uma resposta fora da árvore.

O chatbot é baseado em regras e respostas pré-definidas. A descrição “inteligente” se refere à triagem e ao encaminhamento; o projeto não gera respostas com um modelo de IA.

04 / Construção

Uma base simples de operar e fácil de explicar.

Separar interface, regra de decisão e persistência deixou claro onde o fluxo muda e quais dados são registrados ao final da conversa.

Aplicação

Interface e motor

Python organiza a aplicação; NiceGUI apresenta o chat e o painel administrativo. A árvore JSON permite ajustar mensagens e opções sem misturar conteúdo ao código de interface.

Python 3.12NiceGUIJSONPostgreSQL

Operação

Containers e implantação

O relatório documenta Docker Compose, PostgreSQL 15, proxy Nginx e hospedagem em VPS na Oracle Cloud. O container web usa Python 3.11, enquanto a documentação do projeto também registra Python 3.12.

Docker ComposeNginx Proxy ManagerOracle CloudGitHub

O feedback registra a nota, o primeiro assunto escolhido, comentário opcional, caminho da árvore e data. O relatório também descreve um painel administrativo para consultar essas respostas.
