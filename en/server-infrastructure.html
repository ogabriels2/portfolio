Context and contribution

The Força Aliada community started in 2021. In this part of the project, the problem was to provide access to a self-hosted server without requiring every player to configure a VPN such as Hamachi.

My work includes configuring domains and DNS, integrating tunnel access, following operations and investigating failures. Playit.gg connects the public address to the local server; Cloudflare is used for DNS management and web services. These roles differ: the HTTP proxy is not the path for Minecraft traffic.

The monitor below queries an external service. It supports diagnosis, but a failed query does not prove that the server is offline. The platform and software product development that began in November 2025 is covered in the Força Aliada case study.

Layers and responsibilities

Each layer handles part of the connection. See the Cloudflare proxy limitations and Playit.gg’s tunnel model.

Player access

A public address for connecting to the server, without requiring players to install a VPN.

DNS and web services

DNS associates the domain with its destination. HTTP proxy protection for web services does not automatically apply to the game’s TCP/UDP traffic.

Playit.gg tunnel

The agent forwards connections from the public address to the local service without configuring port forwarding on the router.

Self-hosted server

The Java runtime and plugins run the local server. Configuration and investigation of network problems are part of operations.
